## Claude Commands

Each command runs the matching file in `workflow-prompts/`.

| Command | Purpose |
|---|---|
| `/obsidian-notes` | Vault schema, tags, note formats |
| `/weekly-report` | Write the weekly summary from the current weekly note |
| `/monthly-report` | Draft or update this month's report in `MBR/` |
| `/create-ticket` | Draft an Azure DevOps work item |
