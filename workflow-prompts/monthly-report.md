# Monthly Report

Draft or update the monthly report for a given month (default: the current month).

1. Open `MBR/YYYY-MM.md`. If it does not exist, create it with the structure of `Templates/Monthly Report.md`, writing real values instead of Templater tags.
2. Read the Weekly Summary sections of every note in `Weekly Notes/YYYY-MM/`.
3. Read decisions, `[[brag]]` notes, and task logs that moved to `[[done]]` during the month.
4. Fill in Summary (three to five sentences), Highlights, Learnings, and Next Month. Leave the query blocks alone.
5. Link each highlight to its source note.
6. Skip anything covered by the private rule in `workflow-prompts/obsidian-notes.md`.
7. Follow `workflow-prompts/writing-style.md`.
