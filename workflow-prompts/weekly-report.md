# Weekly Report

Generate a weekly summary from the current weekly note.

1. Find the current weekly note at `Weekly Notes/YYYY-MM/YYYY-MM-DD.md`, where the date is this week's Monday.
2. Read it, plus any task logs in `Notes/` with Progress entries dated this week, decisions dated this week, and meetings in `Meetings/` dated this week.
3. Write a concise summary under `## Weekly Summary` with three parts: done, in progress and blocked, next week.
4. Link each item to its source note.
5. Skip anything covered by the private rule in `workflow-prompts/obsidian-notes.md`.
6. Follow `workflow-prompts/writing-style.md`. Do not overwrite an existing summary; append below it with today's date.
