# Second Brain Vault

This directory is a personal Obsidian vault for a product manager. It holds weekly planning, task logs, meeting and 1:1 notes, decisions, reference knowledge, monthly reports, and personal growth notes.

These instructions apply to any agent working in the vault.

## Vault Rules

Before working with vault files, read `workflow-prompts/obsidian-notes.md`. It defines the folder layout, tags, frontmatter schema, note formats, and agent rules.

When asked about current work, open tasks, or this week's plan, read the current weekly note first. Weekly notes live at:

```
Weekly Notes/YYYY-MM/YYYY-MM-DD.md
```

`YYYY-MM-DD` is the Monday of the current week.

## Workflows

| File | Use it to |
|---|---|
| `workflow-prompts/obsidian-notes.md` | Learn the vault schema, tags, and rules |
| `workflow-prompts/weekly-report.md` | Write the weekly summary in the current weekly note |
| `workflow-prompts/monthly-report.md` | Draft or update a monthly report in `MBR/` |
| `workflow-prompts/tickets.md` | Draft an Azure DevOps work item and link tickets from notes |
| `workflow-prompts/writing-style.md` | Match the expected writing style |

## Writing Style

Be direct and specific. Avoid filler, promotional language, em dashes, and generic summaries. Prefer full sentences over inline-header fragments.
